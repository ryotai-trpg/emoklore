# 効果（Active Effect）

極限共鳴（ハウリング）やシナリオのギミックで得られる、ダイスボーナス・判定値・成功数の修正をこの機能で扱う。

かつては属性キーを手で打ち込む必要があったが、**いまは選択式**になっている。綴りを間違えようがないので、以前あった「大文字小文字も含めて誤字があると動作しない」という注意は要らなくなった。

## 作る

キャラクターシートの**効果タブ**で、区分の見出しにある `＋` を押す。

| 区分 | いつ使うか |
|---|---|
| 一時的効果 | 期限があるもの。「1D3ラウンドの間」「1D10分間」など |
| 永続的効果 | 期限が無いもの。「シナリオの間」「生涯」など |
| 無効 | 作ってはあるが、いまは効かせないもの |

作った効果の鉛筆アイコンから設定を開き、**効果タブ**で中身を決める。

## 修正を1つ足す

`＋` を押すと行が1つ増える。左から順に埋めていく。

| 列 | 何を決めるか |
|---|---|
| 対象 | どの判定に効くか |
| 修正先 | ダイスボーナス／判定値／成功数のどれを動かすか |
| 種別 | 追加・上書きなど、いまの値とどう混ぜるか |
| 効果値 | 動かす量 |
| 段階 | 通常か計算後か（下記） |
| 優先度 | 同じ値を複数の効果が触るときの順序。ふつうは空でよい |

### 対象

ルールブックの言い回しがそのまま選択肢になっている。左列はハウリング表からの引用。

| ルールブックの表現 | 選ぶもの |
|---|---|
| 「全ての技能は判定値-2される」 | 全体 → すべての判定 |
| 「【💪 身体】を使用する技能での判定は成功数-1される」 | 能力値 → 身体 |
| 「交渉系技能での技能判定は成功数-1される」 | 技能グループ → 交渉系 |

特定の技能ひとつだけに効かせたいときは、技能（35件）と基本技能（13件）から直接選ぶ。

基本技能には `＊`、エクストラ技能には `★` が付く。技能グループと基本技能には同じ名前のものがあるので（「調査系」と「調査」）、区分と印で見分ける。

### 修正先

判定は「N個のD10を振り、判定値以下の出目を数える」という形なので、動かせるところが3つある。

| 修正先 | 何が変わるか |
|---|---|
| ダイスボーナス | 振るダイスの数 |
| 判定値 | 各ダイスの目標値。これ以下なら成功 |
| 成功数 | 振ったあとの成功数に足し引きする固定値 |

修正は判定のたびに合算される。同じ判定に「全体」「能力値」「技能グループ」「技能」の4系統が同時に効きうるので、たとえば〈聞き耳〉なら 全体＋五感＋知覚系＋聞き耳 の4つが足し合わさる。

チャットに出る式は内訳が読める形になっていて、修正があると `(2+1)DM≦(5-2)` のように括弧が付く。

### 効果値には式が書ける

数値の欄には計算式も書ける。`2 + 3` でも、他の値を参照する `@` でも通る。

```
@skills.strength.level        〈ストレングス〉の技能レベル
@characteristics.physical.value  【身体】の値
@resources.hp.value           現在HP
@initiative                   行動値
```

参照できるのは[データモデル](/data-model)の `system` 配下（`system.` は書かない）と、`@name` / `@flags` になる。

**ダイスは書けない。** `1d3` のような項は評価できないので、その修正は無かったことになる。「HP-1D3」のようなものは効果ではなく、その場で振って適用する。

### 段階

ふつうは**通常**でよい。**計算後**が要るのは、目標値やHP最大値のような**計算して出している値**を直接動かしたいときだけ。

エモクロアの派生値（技能の目標値・HP最大値・MP最大値・行動値）は、能力値や技能レベルから毎回計算し直される。通常の段階で当てた効果はこの計算に上書きされて消えるので、直接動かしたいなら計算後を選ぶ。

ただし**たいていの場合は計算後を使う必要がない**。「判定値+2」は目標値そのものを書き換えなくても修正先の「判定値」で表せるし、そちらのほうがチャットに内訳が出る。能力値を動かせばHP最大値も行動値も追随する。

計算後が要るのは、たとえば「行動値を+2する」のように、元になる能力値も技能レベルも変えずに結果だけ動かしたいときになる。

### 選択肢に無いキー

対象の一番下に「キーを直接指定」がある。これを選ぶと属性キーを文字列で書く欄になる。

修正の3値以外を触りたいときに使う。

| 書くもの | 何に効くか |
|---|---|
| `system.characteristics.physical.value` | 【身体】そのもの（1〜6に丸められる） |
| `system.skills.spiritualSense.level` | 〈★霊感〉の技能レベル（0〜3に丸められる） |
| `system.resources.resonance.value` | 〈∞共鳴〉の値 |
| `system.initiative` | 行動値（**計算後**を選ぶこと） |
| `system.resources.hp.max` | HP最大値（**計算後**を選ぶこと） |

キーは[データモデル](/data-model)の表にあるパスに `system.` を付けたもの。範囲の決まっている値は、はみ出すと**捨てられずに範囲の端に丸められる**（能力値6に+1しても7にはならず6のまま）。

## 期限

設定シートの**持続時間**タブで決める。値と単位を選ぶ形で、単位は 年／月／日／時間／分／秒 とラウンド／ターンがある。

| ルールブックの表現 | 入れ方 |
|---|---|
| 「1D3ラウンドの間」 | 振った出目を値に、単位はラウンド |
| 「1D10分間」 | 振った出目を値に、単位は分 |
| 「1D10時間の間」 | 振った出目を値に、単位は時間 |
| 「シナリオ中継続」「生涯」 | 期限を入れない（永続的効果のまま） |

ダイスを振るのは人の側になる。「1D3ラウンド」と書いたまま保存はできない。

期限が切れた効果は自動で無効になる。消えはしないので、必要なら手で消す。

## 状態

ルールブックが規定する状態はトークンのHUD（トークンを右クリックして出る輪）から付け外しできる。

**【気絶】【心肺停止】【死亡】【失神】【憑依】【逸脱】**の6つ。ルールに規定は無いが、Foundryの視界と探知が使うため【盲目】【不可視】も残してある。

状態そのものは判定に何もしない。数値の修正が要るなら効果を別に作る。

## 効果はアイテムにも置ける

武器などのアイテムにも効果を付けられる。設定シートの詳細タブにある「キャラクターに効果を適用」にチェックが入っていれば、そのアイテムを持っている間だけ効果がキャラクターに乗る。

## うまく効かないとき

- **効果が「無効」の区分に入っていないか。** 効果タブで区分を確かめる
- **期限が切れていないか。** 切れた効果は自動で無効になる
- **対象を選び忘れていないか。** 足したばかりの行は「選んでください」のままで、選ぶまで何もしない
- **`@` の参照先が合っているか。** 解決できない `@` を含む修正は、丸ごと無かったことになる。綴りは[データモデル](/data-model)で確かめる
- **派生値を直接動かそうとして「通常」のままになっていないか。** 目標値・HP最大値・行動値は計算後でないと残らない
